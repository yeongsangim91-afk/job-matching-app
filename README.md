# 취UP (Job Matching App)

구직자의 현재 역량과 준비 상태를 바탕으로 맞춤형 채용 정보를 매칭하고, 부족한 취업 준비 항목을 제안하는 AI 기반 취업 도우미 웹 애플리케이션입니다.

## 2. PRD (제품 요구사항 정의서)

버전별 기획 및 요구사항 고도화 내역입니다. (최신 버전이 상단에 위치합니다.)

### [PRD v0.6] 비회원 개별 블러 제어 및 화면비 안정화 기준 (2026-11-24)

#### 2.1. 프로젝트 개요 (Overview)
* **서비스명:** 취UP (채용공고 분석 및 역량 기반 취업 매칭 도우미)
* **구현 목표:** 초기 화면 진입 장벽을 낮추면서도 비회원 상태의 개인화·핵심 기능 영역에 항목/페이지 단위 블러 처리와 로그인 유도 버튼을 적용하고, 데스크톱/모바일 브라우저 환경에서 스마트폰 세로 화면비와 스크롤·하단 여백·오버레이 레이아웃을 안정화함.

#### 2.2. 타겟 유저 (Target Audience)
* 로그인 전 서비스의 핵심 메뉴와 추천 흐름을 가볍게 살펴보려는 방문자 및 대학생
* 로그인 후 개인 스펙 기반 매칭 리스트, 목표 기업 합격 진단, 스펙 관리를 활용하려는 취업 준비생

#### 2.3. 핵심 기능 및 요구사항 (Core Features)
1. **온디맨드 로그인 모달 및 비로그인 접근 제어**
   * 최초 진입 시 별도 로그인 게이트웨이 화면을 띄우지 않고 메인 홈부터 탐색 가능하도록 구성하되, 로그인 모달(`#loginModal`)과 `openLoginModal()` 함수를 유지하여 지정된 버튼 클릭 시 즉시 연결.
   * 홈 상단 `'ㅇㅇ님, 반갑습니다!'` 박스는 비로그인 상태에서 블러 처리하고 `'로그인 후 취업 정보를 매칭해보세요!'` 버튼을 제공.
   * 홈 `'내 스펙 완성도'` 영역은 비로그인 상태에서 숨김 처리하고 로그인 시 노출.
   * 홈의 핵심 메뉴 카드, 실시간 매칭률 TOP 3, AI 합격 팁 등 나머지 탐색 요소는 비회원도 접근 가능하도록 유지.
2. **주요 기능 페이지 단위 블러 및 안내 버튼**
   * 맞춤 추천(`#tab-s02`), 목표 진단(`#tab-s03`), 마이페이지(`#tab-s04`)는 비로그인 상태에서 페이지 전체에 블러를 적용하고 `'로그인 후 확인 가능'` 버튼을 통해 로그인 모달로 연결.
3. **화면비 및 뷰포트 레이아웃 고정**
   * 스마트폰 세로 비율(`max-w-md`, 데스크톱 프레임 높이 제한 및 `100dvh` 대응)과 하단 네비게이션 여백을 유지하면서 내부 스크롤 영역과 블러 오버레이가 프레임 밖으로 벗어나지 않도록 구성.

#### 2.4. 기술 스펙 및 아키텍처 (Tech Stack)
* **Frontend:** HTML5 (`index.html`), CSS3 (`css/style.css`), Vanilla JavaScript (`js/main.js`)
* **UI/UX:** Tailwind CSS 기반 모바일 웹뷰 프레임 및 상태 기반 블러/노출 제어

#### 2.5. 향후 계획 (Roadmap)
* 로그인 상태 및 사용자 입력 스펙에 따른 매칭률·스펙 완성도 실시간 계산 고도화
* 채용공고 텍스트 분석 및 AI 역량 진단 기능 확장

2. **맞춤형 채용 매칭 리스트 제공**

3. **채용공고 역량 분석 및 준비 항목 추천 연동 구조**
   * 채용공고 입력 및 AI 기반 역량 분석·부족 역량 진단 기능을 연결하기 위한 기본 데이터 흐름 설계

#### 2.4. 기술 스펙 및 아키텍처 (Tech Stack)

* **UI/UX:** 모바일 환경에 최적화된 반응형 웹 레이아웃 및 인터랙션 적용

#### 2.5. 향후 계획 (Roadmap)
* 실제 생성형 AI API 연동을 통한 채용공고 텍스트 분석 및 역량 추출 기능 고도화
* 사용자 역량 데이터 기반 기업 매칭 알고리즘 정교화

### [PRD v0.2 ~ v0.4] 웹뷰 UI/UX 고도화 및 인증·컴플라이언스 구현 기준 (2026-11-16 ~ 2026-11-17)

#### 2.1. 서비스 개요 (Overview)
* **서비스명:** 취UP (JobUP) - AI 기반 맞춤 커리어 메이트
* **구현 목표:** PC 웹브라우저 환경에서도 스마트폰 앱과 동일한 사용자 경험을 제공하는 모바일 웹뷰(WebView) 풀스크린 레이아웃 구현, 익명성 보호 로그인 및 법적 고지(약관) 체계 확립.

#### 2.2. 핵심 기능 및 요구사항 스펙 (Core Features)
1. **사용자 인증 및 접근 제어 (Authentication & Gateway)**
   * **익명 보호 로그인:** 실명 수집을 지양하고 닉네임 또는 이메일 아이디 기반의 간편 로그인 제공.
   * **로그인 선행 화면 (Gatekeeper):** 비로그인 상태에서 핵심 서비스 접근을 차단하고 최초 진입 시 로그인 전용 화면을 노출.
   * **헤더 동적 버튼:** 로그인 상태에 따라 상단 헤더 버튼이 `로그인` 또는 `로그아웃`으로 자동 전환.
2. **역량 스펙 관리 및 마이페이지 (My Page)**
   * **네비게이션 최적화:** 하단 네비게이션 바의 최우측에 `[마이페이지]` 탭을 배치하여 직관적 접근성 확보.
   * **실시간 스펙 연동:** 학교, 학과, 학점, 보유 자격증, 수강 과목 입력을 통한 매칭률(%) 실시간 계산 및 반영.
   * **계정 관리:** 마이페이지 하단에 시인성이 높은 `[로그아웃]` 버튼과 경고 색상의 `[회원 탈퇴]` 버튼 배치.
3. **AI 맞춤 추천 및 목표 기업 진단 (Recommendation & Diagnosis)**
   * **실시간 매칭률 분석:** 사용자 스펙과 채용 공고 요구 조건 비교를 통한 적합도 점수 산출.
   * **목표 기업 상세 진단:** 주요 IT 기업(네이버, 카카오 등) 대상 충족 조건 및 부족 역량 보완 로드맵 제시.
4. **법적 고지 및 컴플라이언스 (Legal & Compliance)**
   * **이용약관 및 개인정보 취급방침:** 전용 팝업 모달을 통해 서비스 이용 규칙 및 개인정보 최소 수집 원칙 안내.

#### 2.3. 기술 스택 및 배포 환경 (Tech Stack)
* **Frontend:** HTML5, Vanilla JavaScript (ES6+ State Management)
* **Styling:** Tailwind CSS (CDN 기반 상하 여백 제거 및 스마트폰 세로 화면비 고정 웹뷰 레이아웃)
* **Icons:** FontAwesome 6.4.0
* **Deployment:** GitHub Pages

### [PRD v0.1] 초기 기획 및 모바일 와이어프레임 기준 (2026-10-13)

#### 2.1. 프로젝트 개요 (Overview)
* **기획 배경:** 채용공고마다 요구 역량이 달라 핵심 역량을 파악하기 어렵고, 취업 준비생 개인이 자신에게 부족한 역량과 준비 우선순위를 판단하기 어려운 문제를 해결하고자 함.
* **핵심 가치:** 사용자의 현재 역량을 요구하는 적합 기업을 매칭하여 불필요한 취업 준비 시간·비용 낭비를 줄이고, 목표 기업 입사를 위한 맞춤형 준비 항목을 제시.

#### 2.2. 서비스 방향 및 AI 활용 흐름
* **최종 선정 컨셉:** '채용공고 역량 분석(후보 A)'과 'AI 취업 준비 항목 추천(후보 B)'을 통합한 **AI 기반 채용공고 분석 및 취업 준비 도우미**
* **AI 처리 파이프라인:** 희망 직무 및 채용공고 원문 입력 → 생성형 AI를 통한 핵심 요구 역량(기술, 문제해결, 커뮤니케이션 등) 추출 및 현재 준비 상태 비교 → 직무별 요구 역량 요약 및 부족한 준비 항목 추천

#### 2.3. 초기 핵심 화면 설계 (10개 모바일 와이어프레임)
1. **온보딩 / 시작 화면:** 서비스 핵심 가치 안내 및 시작하기 유도
2. **회원가입 / 로그인 화면:** 이메일 로그인 및 소셜 로그인(구글, 카카오)
3. **채용공고 입력 화면:** 채용공고 텍스트 직접 붙여넣기(최대 5,000자) 및 파일 업로드
4. **분석 진행 화면:** AI 역량 추출 및 직무별 요약 로딩 상태 안내
5. **분석 결과 요약 화면:** 기업명, 직무명, 주요 요구 역량 태그 및 역량별 상세 설명 제공
6. **직무별 비교 화면:** 개발, 디자인, 기획 등 직무별 주요 요구 역량 개수 및 핵심 역량 비교
7. **상세 역량 보기 화면:** 채용공고 원문 기반 핵심 역량(1~3순위) 및 추가 역량 상세 조회
